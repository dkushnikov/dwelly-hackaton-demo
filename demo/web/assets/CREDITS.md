# Artwork

All village artwork in `village.js` is original procedural canvas drawing made for this demo: buildings, villagers, trees, flowers, pond, van and envelopes. It has no downloaded sprites or third-party game assets. The artwork is dedicated to the public domain under CC0-1.0.

The interface uses locally available system fonts. No font service, CDN or remote asset is required.

Replay content and synthetic resident records are derived from `lettings-ops-agent` (Apache-2.0). Every bundled replay carries source paths and SHA-256 digests in its opening event. Read `NOTICE` in the project root for provenance and limitations.
