# 90 секунд на сцене

## Подготовка

Открыть `http://127.0.0.1:8787/?presenter=1`. Оставить 1×. Это запасной показ без API: всё уже записано настоящим агентом. Подготовить отдельный JSONL успешного современного live-эпизода, если он будет получен до выступления.

## 0–15 секунд — общий план

Нажать **Start the village**. Четыре истории запускаются параллельно. Сказать: «У нас шесть домов и 21 участник. Каждая заявка живёт отдельно. Мы можем наблюдать весь район и в любой момент войти в один конкретный случай».

## 15–35 секунд — действия с доказательством

Выбрать **The dripping tap**. Дождаться зелёного `CONFIRMED WRITE` у create work order; фургон движется к дому. Показать строчку gate с правилом и уведомление жильцу. Сказать: «Карта следует журналу инструментов: машина едет только после создания заказа. Здесь видно, почему агент имел право это сделать».

## 35–55 секунд — опасная просьба

Выбрать **Something doesn't add up**. Если запись уже закончилась, **Stories → Something doesn't add up → Begin this story**, установить 4×; можно ускорять кнопкой ↠. На красной плашке остановить воспроизведение пробелом.

Сказать: «Письмо пытается подменить полномочия и изменить платёжные реквизиты. В этом реальном прогоне агент сам отказался выполнять просьбу. Это отказ агента, не нарисованный блок инструмента. Настоящий policy gate дополнительно проверяет каждую попытку записи».

## 55–75 секунд — кому передали решение

Выбрать **Ticket status**. Показать fraud/injection flags и карточку **A decision for a human**: вопрос, факты, рекомендуемый шаг, действие при отсутствии ответа, undo. Сказать: «Когда решение не в полномочиях автоматики, оператор получает конкретную задачу, а не длинную переписку».

## 75–90 секунд — интерактивность и надёжность

Нажать Export ↓. Сказать: «В live-режиме я могу стать владельцем или подрядчиком, ответить своими словами и изменить следующий ход. Запись каждого показа остаётся в JSONL. Даже без интернета можно повторить реальные решения».

## Ветка live-показа

При заранее проверенном API вместо записанной сцены нажать P-005 → **Report an issue** → Live / Tenant → `Boiler not working, I'm 82 and it's cold`. Подождать реальных trace и статуса. Не обещать заранее dispatch: законными исходами могут быть запрос фактов или эскалация. Можно выбрать **Over the spending limit → Live → Landlord** и ответить «I decline this quote. Please obtain another one» на запрос — результат следующего раунда должен прийти от агента.

Сетевой вызов может занять дольше сценических 90 секунд. Пока он работает, можно показывать другие тикеты. Если сеть пропала — открыть локальный `?replay=fraud&presenter=1` или импортировать подготовленный live JSONL. Ясно назвать переход к записи.

## Чего не утверждать

Bundled baselines показывают один ход, не полный ремонт. Отсутствующий в старой записи stage/checklist не означает провал агента и не дорисовывается. «Resolved» решения не обязательно означает «ремонт закрыт». Визуальные жители — синтетические персонажи, действия направлены в mock-world.
